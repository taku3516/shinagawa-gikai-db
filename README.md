# 品川区議会DB

品川区議会の公式情報を基に、議会の動きや地域情報を住民が調べやすい形に整理した非公式サイトです。

**[品川区議会DBを開く](https://taku3516.github.io/shinagawa-gikai-db/)**

- **収録対象**: 平成13年〜令和8年（26年分）の議会日程・質問・会議録など
- **技術構成**: HTML / CSS / JavaScriptのみ（フレームワーク・ビルド不要）
- **免責**: 品川区が運営するサイトではありません。正確な議決結果・日程・資料は必ず[品川区議会公式サイト](https://gikai.city.shinagawa.tokyo.jp/)を確認してください。

## このサイトでできること

### 議会情報を調べる

- **年間の流れ・会議の詳細** — 定例会、臨時会、月例委員会を時系列で表示し、公式資料・録画・会議録へ案内
- **会議ワンストップ** — 年と会議を選ぶと、日程、議案、請願・陳情、質問・答弁、委員会質疑、録画、会議録を1ページに集約
- **議案・請願・陳情** — 平成30年〜令和8年は公式ページの掲載分を全件収録。平成27年以降の請願・陳情は、継続審査を含む経過を案件ごとに表示
- **代表質問・一般質問** — 平成13年〜令和8年の全発言項目と、取り下げを除く質問・答弁要約を掲載
- **委員会質疑** — 平成13年〜令和8年の常任・特別・議会運営委員会を、会議日と出典付きで掲載。質疑は要約せず会議録の全文を掲載
- **会議録全文** — 正式会議録が公開されている委員会・本会議は、公式会議録の全文を掲載。委員会は会議を開くとそのまま全文、本会議は質問者から「原文を読む」で該当発言へ移動
- **会議録・録画** — 正式会議録、校正原稿PDF、質問者または会議単位の公式録画へ案内
- **意見書・決議等** — 意見書、決議、要望書、抗議文などを年・種類・キーワードで検索

### 人物・行政資料を調べる

- **議員・政治家名簿** — 現職・元職の区議、都議、衆議、区長を8区分で表示
- **選挙アーカイブ** — 1997年以降の区議選・区長選・都議選を候補者・得票数付きで収録（衆議院選は参考サイトのみ）
- **予算・決算、行政評価、政務活動費、政治資金収支報告書** — 年度別の公式資料を整理して掲載

### 地域情報を調べる

- **品川区ニュース** — RSSと公式サイトから地域ニュースを自動収集し、検索・タグ絞り込み・端末内保存に対応。希望者向けに端末間同期の枠組みも用意
- **町会・自治会区域検索** — 公式境界を地図に表示し、町会名、住所、地域区分、公開プロフィールなどから検索。GPS現在地の表示にも対応

### 読みやすさを調整する

- **横断検索** — 議会、人物、選挙、政務活動費、ニュースなどを年をまたいで検索
- **段階的な開閉** — 会議、資料種別、質問者ごとに表示する情報量を調整
- **スマートフォン対応** — 幅320px以上を対象に、折りたたみナビゲーションや押しやすい操作領域を用意
- **アクセシビリティ設定** — 文字サイズ、高コントラスト、動きを減らす設定を端末内に保存

## 収録範囲と注意事項

- 議会日程、代表・一般質問、委員会質疑は平成13年〜令和8年を対象としています。
- 議案・請願・陳情の全件収録は平成30年〜令和8年が対象です。平成13〜29年は未収録で、追加手順を[実装準備・監査手順](docs/history-expansion.md)に記載しています。
- 請願・陳情の案件別表示は平成27年〜令和8年が対象です。
- 会議録全文は平成13年〜令和8年（委員会3,276会議・本会議429日）を収録しています。本会議は定例会・臨時会の両方が対象です。正式会議録が公開されている会議のみが対象で、校正原稿PDFの段階では掲載しません（機械的な文字の取り出しで崩れが出るうえ、正式版の公開後に公式サイトから削除されるためです）。全文が無い会議は、これまでどおり抜粋・要約と公式会議録へのリンクのみを掲載しています。
- 質疑の抜粋・要約は原文の一部です（委員会の答弁は平均91字）。前後の文脈は「会議録全文」または公式の会議録をご確認ください。
- 要約や言い換えには誤りが含まれる可能性があります。重要な判断には必ず一次情報を利用してください。
- 校正原稿PDFは、正式版の公開後に公式サイトから削除される場合があります。

## ローカルで開く

`index.html`をブラウザで直接開くだけで動作します。HTTPサーバー経由で確認する場合は、リポジトリ内で次を実行してください。

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000/`を開きます。

## 技術概要

- 画面はHTML / CSS / JavaScriptで構成し、GitHub Pagesからそのまま公開します。
- データは`data/*.js`に分離し、`window.SHINAGAWA_DB`へ登録する形式です。
- 会議録全文は`data/minutes/<年>/<会議ID>.js`に委員会1回・本会議1日ずつ分け、その会議を開いたときだけ読み込みます。
- 年データは`data/site.js`の一覧に従って必要になった時点で読み込みます。
- 公式情報の取得、データ生成、品質検査、公開にはPythonスクリプトとGitHub Actionsを使用します。

ページ、ファイル、データ形式の詳細は[サイトとデータの構成](docs/architecture.md)を参照してください。
