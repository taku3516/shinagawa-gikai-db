# 「品川の歴史」の引き継ぎ

別のエージェント（Codex など）に収録作業を引き継ぐための手順書。
**サイトのURLとプロンプトだけ**渡せば続きから作業できるようにしてある。

作業規約は `AGENTS.md`、設計と調査記録は `docs/rekishi-plan.md` にある。
Codex は `AGENTS.md` を自動で読むので、プロンプトで規約を説明する必要はない。

---

## そのまま投げるプロンプト

### A. 通史編 上巻の続き（近世編の残り）

```
https://github.com/taku3516/shinagawa-gikai-db

「品川の歴史」の年表を、品川区史 通史編 上巻の近世編から増やしてください。
AGENTS.md と docs/rekishi-plan.md の §1-10 を読んでから始めてください。

対象は近世編のうち未取得の範囲です。
  （一）町と村      ht001440-ht001799  36節
  （二）行政組織    ht001800-ht002059  26節
  （三）貢租        ht002060-ht002289  23節
  （四）宿駅制度    ht002290-ht002939  65節
  （五）産業        ht002940-ht003299  36節
  （六）生活と文化  ht003300-ht003849  55節

まず toc で節の見出しを見て、年が立ちそうな節を選んでください。
1節1件にはしないこと。取得は11秒あけるので背後で走らせてください。
```

### B. 自然編（地形と災害の素地）

```
https://github.com/taku3516/shinagawa-gikai-db

品川区史 通史編 上巻の自然編（ht000070-ht000649、58節）から、
「品川の歴史」に載せられる事実を起こしてください。
AGENTS.md と docs/rekishi-plan.md を読んでから始めてください。

地形のなりたち・目黒川や立会川の流れ・人為による自然の変化と災害が
中心です。年が立たないものは year: null と yearText で載せてかまいません。
```

### C. 旧町村史（品川町史・大崎町誌・大井町史・荏原町誌）

```
https://github.com/taku3516/shinagawa-gikai-db

しながわデジタルアーカイブの旧町村史から「品川の歴史」を増やしてください。
AGENTS.md と docs/rekishi-plan.md を読んでから始めてください。

品川町史（上中下）・大崎町誌・大崎町郷土教育資料・大井町史・大井町誌・
荏原町誌が https://adeac.jp/shinagawa-city/top/topg/01_history/index.html
にあります。通史編と違い目次からの画像閲覧なので、まず全文テキストが
あるかを確かめ、無ければその旨を docs/rekishi-plan.md に記録してください。
出典台帳 data/rekishi.js への追加が要ります。
```

## 引き継ぎ先が最初にすること

1. `AGENTS.md` を読む（言語・掲載の約束・検査・マージ前の4点）
2. `docs/rekishi-plan.md` の §1-6 〜 §1-10 を読む（調査の経緯と、行き止まりの記録）
3. `git log --oneline -20` で直近の作業を見る
4. `python3 scripts/check_rekishi_data.py` と
   `python3 -m unittest discover -s scripts -p 'test_*.py'` が通ることを確かめる

## 使う道具

| 道具 | 役割 |
|---|---|
| `scripts/adeac_sections.py` | 区史の目次・本文の取得、抽出、和暦を含む文の抽出 |
| `scripts/merge_rekishi_events.py` | 下書きJSONを `data/rekishi-events.js` に追記 |
| `scripts/check_rekishi_data.py` | データの検査（和暦の検算を含む） |
| `scripts/prepare_rekishi_places.py` | 地点データの生成（`rekishi-places.js` は生成物） |

使い方は `AGENTS.md` の「出典を増やすときの手順」にある。
