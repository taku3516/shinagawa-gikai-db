# 令和7年以前の委員会データ拡張台帳

更新日: 2026年7月26日

品川区議会公式会議録検索システムで公開されている委員会記録を対象に、定例会・臨時会以外の委員会を年別ページと横断検索へ追加するための進捗台帳です。

|---|---:|---:|---|

## 対象

- 常任委員会
- 特別委員会
- 議会運営委員会
- 予算特別委員会
- 決算特別委員会
- 各年の公式会議録検索システムに掲載されたその他の委員会

委員会名と検索分類は年度ごとに異なるため、固定した一覧ではなく、公式会議録検索システムの年度別分類から自動取得します。

## 再開方法

共通生成処理は `scripts/prepare_committees.py` です。対象年を西暦で指定します。

```bash
python3 scripts/prepare_committees.py --year 2023
```

生成後は、次を確認してから画面へ接続します。

1. 公式会議録の対象会議数と生成件数が一致している
2. 会議ID・議題ID・質疑IDが重複していない
3. 質問者と答弁者が記録されている
4. 公式会議録へのリンクが有効である
5. 年別ページのアンカーから会議・議題・質疑が開く
6. 横断検索から該当箇所へ移動できる

## 表示と読み込み

年別ページでは、選択した年の委員会データだけを遅延読み込みします。これにより、過去年のデータが増えても最初のページ表示が極端に重くならないようにします。

横断検索では全年度を検索対象にするため、今後さらに5年分を追加する前に、年度別の検索データを必要に応じて読み込む方式への移行を検討します。
