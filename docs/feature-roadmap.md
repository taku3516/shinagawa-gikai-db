# 議会・区政データの統合

既存の URL と公開構成を維持し、静的ページを段階的に拡張する。添付デモは操作と画面構成の参考資料とし、その収録値は使用しない。

| 対象 | 既存データと追加作業 | 配置 |
| --- | --- | --- |
| P01・05・11・13 | 年別データと請願台帳を再利用。会期・案件ごとの審査・表決の詳細は公式資料を照合する | 議案一覧・詳細、既存請願詳細、トップ |
| P15・17 | 台帳のメタデータを再利用。確認履歴と訂正は案件別に管理する | 収録状況、各詳細 |
| P07・09・14 | 財政・行政評価・資金資料索引を再利用。数値と案件間の関連は出典付きで補う | 既存各ページと事業ごとの記録 |
| P02・03 | 名簿、人物台帳、質問、選挙、町会、歴史、ニュース、催しを再利用 | 名簿からの活動ページと地域ページ |
| P04・06・08・10・12 | 既存データの加工、ふりがなの読み、端末保存、出力項目と権利の確認 | 共通メニュー、詳細、既存表示設定 |
| P16 | 区公式の応募方法へ案内する。独自の受付・公開審査には別のサーバー側処理が必要 | 地域・参加 |

独立した用語辞典、誤り報告フォーム、出典付き質問は廃止した。議案の説明・ふりがなと、案件別の出典・確認記録は引き続き表示する。

年別会議の識別子は既存の `meetingId` と暦年 ID を使用する。議案は会議 ID と正規化した公式番号を組み合わせる。番号がない行は配列の順番で識別せず、別途確認する。請願・議員・ニュースには既存 ID を用いる。関連付けは出典のある対応と、単語で探した検索候補を区別する。

追加後は歴史データ検査、Python と Node の既存テスト、ブラウザの代表幅、ファイルを直接開いた場合の表示を確認する。最新の公開環境への反映は承認後に行う。
