# 公開前の残作業

## 公式資料の追加照合

- 議案別の提出・上程・委員会付託・審査・表決の日付と例外経路を追加する。番号のない議案には公式番号を確認できた時点で旧詳細リンクを維持する。
- 表決PDFを会期単位で追加し、列位置、議員ID、当時の会派、議長の不参加、退席・欠席等を照合する。
- 事業ごとの記録は令和7年度評価（令和6年度実施）の652小事業を評価シートから自動で収録済みで、横断検索からも引ける。過去年度の追加、年度をまたいだ同一事業の対応づけ、議案との紐付けは未着手。一致の根拠がある案件だけを結ぶ。
- 請願の事後対応を引き続き区議会だよりと区の公表資料から確認する。
- 個別の政治資金・政務活動費の支出明細は、再配布範囲、領収書の公表範囲、金額を照合する。政治資金と政務活動費の集計を混在させない。
- 会期予定、事業ごとの記録と議案の対応づけ、表決の入力はまだ手作業。既存の定期更新はそのまま使用し、追加の自動収集は公式サイトごとの利用条件と日程・表の変化を確認してから導入する。
- 事業・地域・議員の関係は、確認された関係と語句検索の候補を明確に表示し続ける。

## 運用の決定が必要な接続

- サイト独自の意見募集は、運営主体・保持期間・公開方針の決定、投稿先、連投対策、公開前確認と集計の基盤が必要。ニュースのFirestoreには公開投稿権限を付与していない。
- 公式資料の追加照合後、テーマや大きい文字でのキーボード操作、複数ブラウザとスクリーンリーダーでWCAG適合を検証する。
- ローカルコミット、リモート反映、PR作成、公開検証は承認後。GitHub Pagesの公開前にCIを通し、対象コミットのレビューと未解決スレッドを確認する。
