# 議会・区政の統合データ

| 対象 | ID・結合元 | 更新方法 |
| --- | --- | --- |
| 議案 | `meetingId:正規化した番号`。旧年の番号欠落分は件名・要約・資料URL列から作った識別子 | `data/site.js` の年別本体・追補を参照。同一IDは資料URLをまとめる。旧年の内容修正で識別子が変わる場合は旧リンクを確認する |
| 会議・会期 | 年別データの `meetingId`。公表済み会期で会議台帳が未作成の場合は会期の予定を先行掲載 | 年別データ、`data/civic-sources.js` の `sessions` |
| 請願・陳情 | `data/petitions.js` の `id` | `petitionFollowup[id]` に議会・行政の動きと出典、公式資料の対応を追加 |
| 議員 | 既存人物台帳・名簿の `id`。既存IDがない質問は、同名の区別がつく場合に限り人物台帳の別表記を参照 | `people.js`、議員名簿、年別質問、`speaker-members.js` |
| 会派・表決 | 当時の会派と議員IDを表決資料の列順で、会期ごとに記録。表決1件は議案IDと同じで、`session` に会議IDを持つ | `voteSessions[会議ID]`（`roster`・`chairColumn`・出典）と `votes`。列数・並び順は会期で変わるため、議員の記号は `civic.memberVote` で引く。議長の不参加、欠席、退席、除斥、棄権、賛否は別値 |
| 事業 | 事業に付与した `id` | `projects`。出典で確認した経過・議案ID・関係資料を登録。名称・所管等の履歴を追加できる |
| 予算・決算 | `fy-r07` 等の既存年度ID | `data/fiscal.js` と `budgets` を参照。金額は円、人口は人、基準日はISO日付 |
| 政務活動費 | 正規化済みの年度・期間・報告主体ID | `data/seimu.js` と `data/seimu-summary.js` の会派IDを結合し、政務活動費ページに会派別の費目集計を表示。政治資金は団体IDと対象年で別管理 |
| 地域 | `rekishiAreas` の既存地区ID、町会データの地域センター・町丁目表示名 | 地区別の歴史・町会を参照。記事の収録地名と催しの本文・場所の文字列照合は、関連候補として表示 |
| ニュース | `data/news-items.js` の `id` | 既存収集をそのまま使用。記事の公開日と取得日を区別 |
| 確認記録 | 対象ID | `reviews` でAI利用、人の確認日、訂正履歴を管理。機械による出典照合日と人の確認日を区別 |

CSVとJSONの出力項目は `civic-catalog.js` を共通に使う。連絡先・住所・原文・画像は含めない。金額・票数の表示文字列に含まれる単位と、数値型の円額を区別する。欠損はJSONの `null`、CSVの空欄とする。

`scripts/build_civic_feeds.mjs` は公開成果物に収録件数とRSSを書き出す。年別データと請願台帳から生成し、サイト更新作業で別途件数を手入力する必要はない。
