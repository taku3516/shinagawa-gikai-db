# 「品川の歴史」品質点検の記録

第6段階（品質確認）で実施した点検と結果です。点検は2026年11月20日に、
全22ページをiframeで読み込み、DOMから実測する一時ページで行いました。
点検ページは使い捨てなので、リポジトリには残していません。

## 点検のやり方

各ページを**1280px幅と320px幅の両方**で読み込み、次を測りました。

- JavaScriptのエラーと `console.error` の呼び出し
- ページ全体の横方向のはみ出し（`documentElement.scrollWidth` と幅の比較）
- 見出しの階層（h2を飛ばしてh3へ行っていないか）
- 文字と背景のコントラスト比（背景は祖先をたどって合成し、半透明も重ねて計算）
- 操作領域の大きさ（本文中のインラインリンクは除く）
- 本文中のリンクから下線が消えていないか
- `lang`、`h1`の数、`main`、`alt`の有無、共通ナビの群の数

### 詰まりどころ

**点検ページのiframeは、毎回ちがうURLにしないと古いHTMLを見続けます。**
最初の実行では、直したはずの見出しの問題が残って見えました。`?audit=1` のように
固定のクエリを付けていたためで、毎回の時刻を混ぜて解決しました。
（CSSで同じことが起きた記録が `docs/` 外のメモにあります。HTMLでも起きます。）

### 直したこと

1. **年表の時代見出しが見出し要素ではなかった。** 折りたたみの見出しが `<span>`
   だったため、h1の次がいきなりh3になっていました。`<h2>` にしました。
2. **地図の吹き出しの見出しが h3 だった。** 歴史マップと古地図・今昔比較は
   ページ内にh2が無く、吹き出しを開くとh1→h3に飛んでいました。`<h2>` にしました。
3. **重ねる地点のチェックボックスが小さかった。** 囲みのラベル全体が押せるように
   してありましたが、四角だけを狙う人のために24pxにしました。
4. **年表の「品川区が最初の文化財を指定する」が事実と違っていた。** 下記参照。

### データの再点検で見つかった誤り

第2段階で書いた年表の項目が、第3段階で集めたデータと食い違っていました。

- **誤**：最初の区指定文化財は昭和53年11月22日（品川神社石造鳥居並水盤ほか）
- **正**：昭和53年**2月14日**に天然記念物16件が先に指定されている。11月22日は23件

品川地区のページだけを見て書いたためです。全地区のデータを数えて気づきました。
年表の記述を直し、両方の日付と件数を載せています。

**教訓**：1つの地区のページから全体の「最初」を結論しない。数えられるものは数える。

## 既存ページで見つかった、直していないこと

歴史機能の変更範囲を最小限に保つため、既存ページの以下は**直していません**。
いずれも今回の変更で生じたものではなく、以前からあるものです。

- `ikensho.html`、`senkyo.html`、`chokai-map.html` で見出しがh1からh3へ飛んでいます。
  いずれも、見出しに見える部分が `<span>` や `<summary>` の中にあるためです。
- `kaigi.html`、`seigan.html` に、高さ17〜18pxのリンクがあります。
  本文中のリンクではなく、見出しや表の中の単独のリンクです。
