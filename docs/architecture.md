# サイトとデータの構成

品川区議会DBのページ、共通ファイル、データ形式、表示上の設計をまとめます。データの取得・再生成方法は[データの更新方法](data-maintenance.md)、GitHub Actionsの動作は[自動更新とGitHub Actions](automation.md)を参照してください。

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（各ページへの入口） |
| `kaigi.html` | 会議ワンストップ（日程・議案・質問答弁・録画・会議録の集約） |
| `kaigiroku.html` | 年ごとの会議・議案・請願陳情・質問・委員会質疑 |
| `ikensho.html` | 意見書・決議等の検索・一覧 |
| `seigan.html` | 請願・陳情（案件ごとの審査経過・委員会審査・個別ページ） |
| `kensaku.html` | 横断検索 |
| `giin.html` | 議員・政治家名簿 |
| `senkyo.html` | 選挙アーカイブ |
| `yosan-kessan.html` | 予算・決算 |
| `gyosei.html` | 行政評価 |
| `seimu.html` | 政務活動費 |
| `seijishikin.html` | 政治資金収支報告書 |
| `news.html` | 品川区ニュース |
| `chokai-map.html` | 町会・自治会の住所区域検索とOpenStreetMap |

## 技術構成

- HTML / CSS / JavaScriptのみで動作し、フレームワークやビルドは不要です。
- データは`data/*.js`に分離し、`window.SHINAGAWA_DB`へ登録するスクリプト形式です。
- `index.html`を直接開く場合と、GitHub PagesなどのHTTPサーバーから開く場合の両方に対応します。

## 共通表示ファイル

- `site-nav.css` / `site-nav.js` — 全ページ共通のナビゲーション。スマートフォンでは折りたたみます。
- `site-mobile.css` — タップ領域、入力欄の文字サイズ、表の横スクロールなど、スマートフォン向けの共通調整です。
- `site-a11y.css` / `site-a11y.js` — 文字サイズ、高コントラスト、動きを減らす設定、本文スキップリンク、端末内への設定保存を扱います。

## 主なデータファイル

### 共通・人物

- `data/site.js` — 共通設定と年の一覧。各ページはこの`years`を見て年データを読み込みます。
- `data/members.js` / `data/former-members.js` — 現職・元職の区議名簿です。
- `data/politicians.js` — 現職・元職の都議、衆議、区長名簿です。
- `data/people.js` — 質問者と議員を紐付ける人物台帳で、表記揺れの名寄せにも使います。

### 議会・行政

- `data/petitions.js` — 請願・陳情を受理番号で名寄せした自動生成台帳です。
- `data/petitions-official.js` — 公式ページから取得した付託委員会、受理年月日、議決結果です。
- `data/resolutions.js` — 公式「意見書・決議等」から取得した意見書、決議などです。
- `data/elections.js` — 品川区の選挙アーカイブデータです。
- `data/seimu.js` — 政務活動費の年度・会派・議員別公式資料です。
- `data/seijishikin.js` — 政治団体の収支報告書データです。
- `data/fiscal.js` — 予算・決算の年度別公式資料です。
- `data/gyosei.js` — 行政評価（事務事業評価・政策評価）の年度別公式資料です。

### ニュース・町会

- `data/news-items.js` — 自動収集したニュースです。
- `data/chokai.js` — 13地域センターの町会・自治会名と住所区域です。
- `data/chokai-boundaries.js` — 品川区「しながわMAP」の公式Shapeから変換した町会境界GeoJSONです。
- `data/chokai-profiles.js` — 連合会・しながわすまいるネットで公開されている町会長、連絡先、紹介、活動、ウェブサイト、SNSです。

### 年別データ

- `data/h13.js`〜`data/h29.js` — 平成13〜29年の会議、質問、答弁要約です。議案・請願陳情は未収録です。
- `data/h30.js`〜`data/r08.js`と各`-complete.js` — 平成30年〜令和8年の基礎データと全件表示用補足データです。
- `data/h13-committees.js`〜`data/r08-committees.js`と分割ファイル`-part-NN.js` — 年別の委員会質疑・答弁要約です。

## 年データの読み込み

`data/site.js`の`years`は、会議録ページ（`kaigiroku.html`）と横断検索（`kensaku.html`）が年データを読み込むための共通一覧です。新しい年の追加方法は[データの更新方法](data-maintenance.md#過去年未来年の追加)を参照してください。

## リンクの種類と色

| 型 | 色 | 用途 |
|---|---|---|
| `official` | 青 | 公式資料・日程へのリンク |
| `video` | 赤 | インターネット中継の録画へのリンク |
| `minutes` | 緑 | 会議録検索システムの正式版へのリンク |
| `minutesDraft` | 緑 | 校正原稿PDFへのリンク |

`minutesDraft`の校正原稿PDFは、正式版公開後に公式サイトから削除される場合があるため、該当リンクがある場合は注意案内を表示します。

## スマートフォンとアクセシビリティ

- サイトの全14ページを対象に、幅320px以上でページ全体の横方向のはみ出しが出ないよう調整しています。
- 画面幅640px以下では、共通ナビゲーションの14リンクを「☰ メニュー」にまとめ、現在のページ名をボタンに表示します。
- 入力欄と選択欄は16px以上とし、iOSで操作時に画面が自動拡大しにくいようにしています。
- 選挙結果など横に長い表は、案内を表示したうえで表だけを横スクロールできるようにしています。
- ボタンとリンクには原則44px以上の操作領域を確保しています。
- 文字サイズ、高コントラスト、動きを減らす設定は全ページ共通で利用でき、端末内に保存します。
- パソコン向け表示では、折りたたみメニューは表示しません。
